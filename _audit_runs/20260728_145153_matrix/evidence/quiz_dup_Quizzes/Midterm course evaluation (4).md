# Midterm course evaluation

Allowed Attempts: 1URL: <https://cbscanvas.instructure.com/courses/43660/quizzes/107367>

The purpose of the mid-term evaluation is to initiate a dialogue between teachers and students early on in each course. This dialogue can both serve to improve the organisation of the course's structure and content and it also serves the purpose of aligning expectations between teachers and students.

The mid-term evaluation is based on a brief survey where the students answer two closed questions and two open questions.

*Information aimed at teachers and course coordinators:*

Course coordinators and teachers are adviced to plan and execute a midterm evaluation in the course approx. 1/3 into the course. The evaluation is considered a tool in order to adjust the remaining classes if an adjustment is necessary.

The evaluation method is up to the single teacher. 

Guidance on how to add the activity 'Midterm course evaluation' is available [here](https://cbsshare.cbs.dk/eduservices/evalueringsenheden/Pages/Midterm-evaluation.aspx).
