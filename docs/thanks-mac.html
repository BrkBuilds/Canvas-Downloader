Canvas Downloader is free and indie, so it isn't signed with Apple's paid certificate. That means macOS needs you to approve it once, by hand. It takes about a minute — here's exactly how.

Before you start — requirements
🖥️
Apple Silicon Mac (M1 or newer)

This build runs on M1, M2, M3 and M4 Macs. It does not run on older Intel Macs. Not sure? Click the Apple menu → About This Mac and look for "Apple M…" next to Chip.

Installing
  • 1. Open the DMG: Double-click the downloaded .dmg file to mount it.
  • 2. Install: In the window that opens, drag the Canvas Downloader icon onto the Applications folder.
  • 3. First open: Open your Applications folder and double-click Canvas Downloader. macOS will block it the first time — this is normal for free apps. Use one of the two methods below to approve it.
METHOD 1 · RECOMMENDED Approve it in Settings
  • Double-click the app. You'll see "Apple could not verify…" or "unidentified developer" — click Done.
  • Open the Apple menu → System Settings → Privacy & Security.
  • Scroll down to the Security section. You'll see "Canvas Downloader was blocked…" with an Open Anyway button. Click it.
  • Enter your Mac password / Touch ID if asked, then click Open Anyway once more to confirm.
  • On macOS 14 Sonoma or earlier there's a shortcut: just right-click the app → Open → Open. (On macOS 12 and earlier the settings page is called System Preferences → Security & Privacy → General.)
METHOD 2 · IF IT SAYS "DAMAGED" One Terminal command

If macOS says Canvas Downloader is "damaged and can't be opened", or Method 1 didn't show an Open Anyway button, this clears the download flag. Open Terminal (Spotlight → type "Terminal"), paste the line below exactly, and press Return:

xattr -dr com.apple.quarantine "/Applications/Canvas Downloader.app"

Nothing visible happens — that's expected. Now go back to Applications and double-click the app; it opens normally. (This only works if you put the app in your Applications folder in step 2.)

You only do this once. After the first launch, open Canvas Downloader normally from Launchpad or Applications.
