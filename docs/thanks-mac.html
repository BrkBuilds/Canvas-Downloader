Because Canvas Downloader is an indie app, macOS requires a specific way to open it the very first time. Here is the 10-second guide.

Apple Silicon Only

This beta is built for M1/M2/M3/M4 Macs. It will not run on older Intel Macs.

  • 1. Open the DMG: Double-click the downloaded .dmg file to mount it.
  • 2. Install: Drag the Canvas Downloader icon into the Applications folder.
  • 3. The Gatekeeper Bypass: Go to your Applications folder. Right-click (or Control-click) the app and select Open.
  • 4. Confirm: macOS will show a warning about an unidentified developer. Click Open again.

You only have to do the Right-click trick once. After that, you can launch it normally from Launchpad.
