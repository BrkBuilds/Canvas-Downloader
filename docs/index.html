Setup

Up and running in 3 steps

No installation headaches. No account creation. Just paste your Canvas token and go.

1

Get your Canvas API token

Your token stays on your device. It never reaches any server.

2

Select your courses

The app loads your full course list. Tick the ones you want — current semester, all time, or just favorites.

Save a group so next semester takes 5 seconds.

Getting your Canvas API token

Canvas Downloader needs an API token to access your courses. It never leaves your device — it's stored locally and only used to talk to your university's Canvas server directly.

1

Log in to Canvas at your university (e.g. canvas.university.edu)

2

Click your profile picture (top left) → Account → Settings

3

Scroll to Approved Integrations → click + New Access Token

4

Give it a name (e.g. "Canvas Downloader"), set an expiry, and click Generate Token

5

Copy the token and paste it into Canvas Downloader — that's it

Your token is safe. It's stored only on your device, used exclusively to call your university's own Canvas API, and never transmitted to any third-party server. Canvas Downloader has no backend, no analytics, no telemetry. It's just a local app.
What the token can access
✓ Your course files and content
✓ Your assignments, syllabus, grades
✓ Read-only — cannot submit or modify anything
— Other students' data: not accessible
— Admin or instructor features: not accessible
FAQ

Common questions

Is this allowed by my university?

Canvas Downloader only accesses files and content you already have permission to view as a student. It uses the official Canvas API — the same one that Canvas's own mobile apps use. You're downloading your own course materials, not anything restricted.

Is it really free? What's the catch?

Yes, completely free. No subscriptions, no premium tier, no ads. It's an open-source project built by a student for students. You can read every line of code on GitHub.

Will it work with my university's Canvas?

Almost certainly yes. Canvas is used by over 30 million students worldwide. Canvas Downloader uses the standard Canvas REST API that works with every Canvas institution. As long as you can log into Canvas at your university, it will work.

Do I need to install Python or anything else?

No. The app is fully self-contained — Python is bundled inside the executable. For optional conversions (PowerPoint → PDF, video → audio), you'll need the relevant app (Microsoft Office or LibreOffice, FFmpeg) but none are required for the core download functionality.

What happens when my professor updates a file?

In Sync Mode, the app detects the update. If you haven't edited the file, it replaces it cleanly. If you've annotated or edited it, the new version is saved as filename_NewVersion alongside yours — your work is never lost.

The macOS/Windows security warning scared me — is the app safe?

Yes. The warning appears because we haven't paid for a code-signing certificate ($99–$300/year for an indie project). The app's source code is fully public on GitHub — anyone can read it and verify it does exactly what it says. Thousands of legitimate open-source apps show the same warning.

Can the app see my other Canvas students' data?

No. Your API token only grants access to your own student account — courses you're enrolled in, files available to you, your own grades and submissions. There is no way to access other students' data through the student API.

Found a bug or want a new feature?

Open an issue on GitHub Issues. Pull requests are also welcome — it's an open-source project and contributions are appreciated.
