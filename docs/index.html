Security

Fair questions, straight answers.

Downloading an unsigned app that has "Canvas" in its name - around the time of a Canvas security incident - is a completely reasonable thing to be cautious about. Here's what's actually going on.

Why is Windows / Mac warning me?

Code-signing certificates - the thing that makes these warnings go away - cost $99-$300 per year, paid to Apple or Microsoft. This is a free project built by a student. The same popup appears for VLC, Blender, and most other open-source software that doesn't pay for the certificate. The warning means "unrecognized publisher," not "dangerous."

The certificate program isn't a safety check - it's a publisher registry. Any developer, including a malicious one, can buy one and appear clean to your OS. Skipping it doesn't say anything about the code.

What does it actually connect to?

Only your university's Canvas server - the same URL you log into in your browser. There's no backend, no analytics server, no developer receiving anything from your machine. Your API token is stored in your OS's password vault (Windows Credential Manager or macOS Keychain), not in a file on disk, and is only sent to your university's Canvas when downloading.

The app's local interface runs on 127.0.0.1 - your own computer only. It cannot be reached from the internet or your local network. None of this requires trusting our word: the source code is publicly readable on GitHub.

What about the Instructure / Canvas breach?

This app has no connection to Instructure beyond using their public student API - the same one used by the Canvas mobile apps and other third-party integrations. It's not built by them, not affiliated with them, and the breach happened on their servers, not on your computer. Using this app doesn't change your exposure to that incident in either direction.

The practical step is the same regardless of this app: update your Canvas password, and in Canvas → Account Settings → Approved Integrations, remove any API tokens you don't recognize.

You don't have to take our word for it

The full source code is public on GitHub and has been since the beginning. If you're unsure, read it before downloading - that's exactly the right approach. The things worth checking are in three files: start.py (server binds to 127.0.0.1), canvas_logic.py (all requests go to your Canvas URL), and ui/auth.py (token saved to OS keyring, never written to a file).

If you're not a developer, the fact that the source is fully public and has been since day one is itself the most meaningful signal.

Getting your Canvas API token

Canvas Downloader talks directly to your university's Canvas server using your own API token. It never contacts any third-party server.

1

Log in to Canvas at your university (e.g. canvas.university.edu)

2

Profile picture (top left) - Account - Settings

3

Scroll to Approved Integrations - click + New Access Token

4

Name it (e.g. "Canvas Downloader"), set an expiry, click Generate Token

5

Copy the token and paste it into the app. Done.

Your token is safe. It's stored only on your device, used exclusively to call your university's Canvas API, and never sent anywhere else. The app has no backend, no analytics, no telemetry.

FAQ

Is this allowed by my university?

Canvas Downloader only accesses files you already have permission to view as a student. It uses the official Canvas API - the same one the Canvas mobile apps use. You're downloading your own course materials.

Is it really free? What's the catch?

Free with no catch. No subscription, no premium tier, no ads. It's an open-source project. Read every line of code on GitHub.

Will it work with my university's Canvas?

Almost certainly. Canvas Downloader uses the standard Canvas REST API, which works with every Canvas institution. If you can log into Canvas at your university, it works.

Do I need Python or anything else installed?

No. Python is bundled inside the executable. For optional conversions (PowerPoint to PDF, video to audio), you need the relevant app - Microsoft Office or LibreOffice - but none are required for downloading.

What happens when my professor updates a file?

In Sync Mode, the app detects the update. If you haven't edited the file, it replaces it. If you've annotated it, the new version is saved as filename_NewVersion next to yours - your work is never lost.

The security warning scared me - is it safe?

Yes. The warning appears because code-signing certificates cost $99-300/year and this is an indie project. The full source code is public on GitHub. Thousands of legitimate open-source apps show the same warning.

Can it see other students' data?

No. Your API token only grants access to your own student account - courses you're enrolled in, files available to you, your grades. There is no way to access other students' data through the student API.
