FAQ

Frequently Asked Questions

Quick answers to the most common questions about Canvas Downloader.

What is the difference between Download Mode and Sync Mode?

Download Mode fetches a complete fresh copy of everything â€” it has no memory of previous downloads. Sync Mode tracks every file in a hidden database, compares your local folder against Canvas, and only fetches what's new or changed. Use Download Mode for a first-time backup; use Sync Mode for ongoing maintenance.

What happens to my edits if I sync an updated file?

Your edits are 100% safe. The app downloads the new Canvas version and saves it as filename_NewVersion alongside your original. Your annotated file is never overwritten.

Why are some files unchecked by default?

The app protects your intentional actions. Files you've edited locally are unchecked to avoid cluttering your folder with _NewVersion files unless you explicitly ask. Locally deleted files are unchecked because your deletion is respected.

If I uncheck a file, will it ask me again next time?

Yes. Unchecking means "skip for today." The file is still pending sync and will show up on the review screen next time. To permanently skip it, use the Ignore icon (ðŸ‘ï¸) or the "Move deselected to Ignored" button.

I renamed or moved a file locally â€” will sync break?

No. The app automatically detects renamed and moved files using content fingerprinting. You can rename and reorganize freely â€” no duplicates, no broken tracking.

Will a file show as updated if the teacher only changed its description?

No. The app compares file content fingerprints, not just timestamps. If the actual file content hasn't changed, it stays in Up to Date â€” no phantom updates.

Will Sync re-download files I already have?

No. The app scans your existing folder and automatically recognizes files you already have using a smart algorithm. They are marked as Up to Date â€” no wasted bandwidth.

I moved my course folder to a different drive. Will sync still work?

Click the edit icon on the pair and re-select the folder at its new location. The hidden database lives inside the folder, so all sync history is preserved automatically.

If I enable PowerPoint to PDF, does the original get deleted?

Yes â€” the original is replaced by the PDF. Same for Legacy Word to PDF and Video to Audio. Exception: Excel keeps the original alongside the new PDF and data file.

What does Submissions (Results) save, and will my professor know?

It saves feedback and grades you received on your own submitted work â€” professor comments, rubric scores, and your grade per assignment. This is your personal data. Your professor is not notified.

What is the "â˜ï¸ Canvas Updates & Deletions.txt" file?

An automatic log inside each course folder that records every update and teacher deletion after each sync. It only appears if your teacher updated or deleted files.

Do the AI conversions work on all computers?

It depends. PowerPoint and Word conversions require Microsoft Office or the free LibreOffice. Video to Audio requires FFmpeg. If not installed, that conversion is silently skipped. Archives, Canvas pages, code files, and web links work everywhere with no extra software.
