macOS Setup Guide

Canvas Downloader is a free, indie app, so macOS asks you to approve it with a few one-time dialogs. The assistant below guides you through every step, tailored to your macOS version. It takes about two minutes.

Prefer reading? See the full step-by-step guide, with screenshots ▶
Before you start
  • Apple Silicon Mac - M1, M2, M3, M4 or M5 chip (not Intel)
  • macOS 11 Big Sur or later - Monterey, Ventura, Sonoma, Sequoia, Tahoe all work
  • Microsoft Office - optional. Only needed for PDF conversions (PowerPoint / Word / Excel → PDF). Everything else works without it and original files are always kept.
Step 1

Install

  1. Double-click the downloaded .dmg file to mount it.
  2. In the window that opens, drag Canvas Downloader onto the Applications folder.
  3. Eject the DMG - the app now lives in your Applications folder and is ready to open.

Drag the icon onto the Applications folder, just like the clip above.

Step 2

Open for the first time

The full first-open process, start to finish (shown on macOS Sequoia).

Open your Applications folder and double-click Canvas Downloader. Because the app doesn't have Apple's paid developer certificate, macOS blocks it on the first attempt - this is normal for every free and open-source app.

First, you'll see this:

Click Done (not "Move to Trash"). Then open Apple menu → System Settings → Privacy & Security and scroll to the Security section. You'll see "Canvas Downloader was blocked…" - click Open Anyway.

macOS then asks you to confirm your identity:

→ Enter your Mac login password and click Open Anyway to confirm.

Canvas Downloader is open-source - you can read every line of what it does on GitHub. The password step is macOS's standard safety gate for all unsigned apps, regardless of what they do.

macOS 14 Sonoma or earlier: you can skip the Settings detour entirely - just right-click the app → Open → Open.  ·  macOS 12 or earlier: the settings path is called System Preferences → Security & Privacy → General.
▶ The app says "damaged and can't be opened"?

Open Terminal (Spotlight → type "Terminal" → press Return), paste the line below exactly, and press Return. Nothing visible happens - that's expected. Then go back to Applications and double-click the app normally.

xattr -dr com.apple.quarantine "/Applications/Canvas Downloader.app"

This removes macOS's quarantine flag. It only works if the app is in your Applications folder (step 1).

Step 3

Allow notifications

When the app opens, macOS shows a notification permission prompt in the top-right corner of your screen. Click it to open the permission dialog:

→ Click Allow to enable notifications.

Once allowed, the toggle in Notification Settings looks like this:

Canvas Downloader sends one "Download Complete" or "Sync Complete" banner when a long run finishes - so you can step away and get notified when it's done. No other notifications are ever sent.

▶ Missed the prompt? Enable notifications manually.

Go to System Settings → Notifications → Canvas Downloader. Turn on Allow Notifications and set the style to Banners or Alerts - the "None" style suppresses all banners even when notifications are technically allowed.

Step 4

Log in to Canvas

Creating a Canvas Access Token takes about 30 seconds - the clip shows exactly how.

Enter your institution's Canvas URL (e.g. https://school.instructure.com) and a personal Canvas Access Token in the sidebar.

Tap the ? button next to the Canvas Access Token field for a step-by-step guide to generating one from your Canvas account settings - it takes about 30 seconds and requires no special permissions.

Step 5

First download - one-time permissions

Stay at your Mac for the first minute of your first download and click Allow on each dialog. They appear once, and never again.

When you start your first download or sync, Canvas Downloader asks macOS for all remaining permissions up front - so they never interrupt a run later. Up to six dialogs appear in sequence, depending on which Microsoft Office apps you have installed.

1
App Data Access macOS 15 + only
"Canvas Downloader" would like to access data from other apps.
"Keeping app data separate makes it easier to manage your privacy and security."
→ Click Allow.

PDF conversions use a private scratch folder inside Microsoft Office's own app container - macOS 15 Sequoia flags that as "another app's data." On macOS 14 and earlier this dialog simply never appears.

2
Downloads Folder
"Canvas Downloader" would like to access files in your Downloads folder.
"Canvas Downloader may save downloaded course files to your Downloads folder."
→ Click Allow.

macOS asks once per protected folder. If you save files to a custom folder (Documents, Desktop, or elsewhere) you'll see this dialog for that folder instead.

3
System Events
"Canvas Downloader" wants access to control "System Events".
"Allowing control will provide access to documents and data in "System Events", and to perform actions within that app."
→ Click Allow.

System Events is the macOS automation layer that keeps Office windows hidden during conversions - nothing flashes or bounces in the Dock while files are being processed.

4
Microsoft PowerPoint
"Canvas Downloader" wants access to control "Microsoft PowerPoint".
"Allowing control will provide access to documents and data in "Microsoft PowerPoint", and to perform actions within that app."
→ Click Allow.

This is the PDF-conversion permission. Canvas Downloader opens each .pptx file in PowerPoint, exports a PDF locally, and closes it again - nothing is uploaded anywhere.

5
Microsoft Word
"Canvas Downloader" wants access to control "Microsoft Word".
"Allowing control will provide access to documents and data in "Microsoft Word", and to perform actions within that app."
→ Click Allow.
6
Microsoft Excel
"Canvas Downloader" wants access to control "Microsoft Excel".
"Allowing control will provide access to documents and data in "Microsoft Excel", and to perform actions within that app."
→ Click Allow.

Dialogs 4-6 only appear for Office apps you have installed. If you don't have Office, none of them appear and original files are always kept as-is.

That's everything. Every later download and sync runs completely hands-free.

Troubleshooting

Something went wrong?

I clicked "Don't Allow" on an automation dialog.

Go to System Settings → Privacy & Security → Automation → Canvas Downloader and switch on the entry you denied (Microsoft PowerPoint, Word, Excel, or System Events). Then run the download again.

Some files say "timed out" or were skipped during conversion.

A permission dialog was probably waiting unanswered while you were away - this can only happen on the very first run. Once all dialogs have been answered, run a Sync on the same folder and it will pick up any skipped files.

I denied access to my Downloads, Documents or Desktop folder.

Go to System Settings → Privacy & Security → Files and Folders → Canvas Downloader and enable the folder you want to save into.

No "Download Complete" notifications are appearing.

Go to System Settings → Notifications → Canvas Downloader. Turn on Allow Notifications and set the alert style to Banners or Alerts - the default "None" blocks all banners.

The app won't open or says "damaged".

See Step 2 above - the Terminal xattr -dr command clears macOS's quarantine flag from the app.
